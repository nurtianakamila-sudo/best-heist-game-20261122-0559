The Gilded Vault — a midnight heist game in the browser. Slip through a museum gallery as a hooded thief: dodge patrolling guards and their vision cones, slip past sweeping security cameras, time the laser tripwires, pocket the loot, and vanish through the exit before the alarm meter hits 100% and the room locks down. Three rooms, escalating guards, cameras and lasers, coin tosses to lure guards away, sneak mode, ghost bonuses, and a clean-getaway score.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, hold SHIFT to sneak, click to toss a coin that lures a nearby guard. No network needed — the game runs from its own static files.
